### Implementation Details

The solution is implemented in `/home/user/langwatch-csv-pipeline/pipeline.py` and provides both `export` and `import` subcommands.

1. **CLI Design & Subcommands**:
   - `python pipeline.py export --input <records.json> --output <dataset.csv>`
   - `python pipeline.py import --input <dataset.csv> --output <records.json>`

2. **Handling Oversized Fields**:
   - Built a robust `set_field_size_limit()` helper that safely increases Python's standard `csv.field_size_limit` to prevent `_csv.Error: field larger than field limit (131072)` errors when reading/writing large dataset cells.
   - It handles `OverflowError` gracefully by trying a list of fallback candidates (e.g., `sys.maxsize`, `2**31 - 1`, down to standard limits), ensuring compatibility across different operating systems and architectures.

3. **Export Subcommand (`export`)**:
   - Reads canonical JSON evaluation dataset records.
   - Writes the CSV file with the exact header row: `index,question,expected_output,contexts,conversation_history`.
   - Serializes the nested columns `contexts` (array of strings) and `conversation_history` (array of objects) as compact JSON inside a single CSV cell using `json.dumps(value, ensure_ascii=False, separators=(",", ":"))`.
   - Correctly quotes and escapes cells containing commas, double quotes, and embedded newlines using the standard Python `csv` module with `newline=''` and standard excel dialect.
   - Tracks the maximum character length of unquoted field values (`max_field_chars`).
   - Computes SHA-256 hex digests of the compact JSON representation of the nested fields for each record.
   - Emits a machine-readable JSON report prefixed with `LANGWATCH_CSV_REPORT ` as the final line of stdout.

4. **Import Subcommand (`import`)**:
   - Reads the CSV file produced by `export` (handling fields larger than 131072 characters).
   - Reconstructs the exact original records into the output JSON file.
   - Restores `index` as an integer and JSON-decodes the nested fields back into their native list/object form.
   - Tracks `max_field_chars` and computes the record SHA-256 checksums.
   - Emits the machine-readable JSON report prefixed with `LANGWATCH_CSV_REPORT ` as the final line of stdout.

5. **Report Format**:
   ```json
   LANGWATCH_CSV_REPORT {"operation":"export|import","record_count":4,"max_field_chars":200005,"field_size_limit":9223372036854775807,"checksums":{"0":{"contexts":"<sha256hex>","conversation_history":"<sha256hex>"},...}}
   ```
