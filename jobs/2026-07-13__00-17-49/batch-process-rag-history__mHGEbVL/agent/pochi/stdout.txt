## What the script does

1. **Reads run-id** from `/logs/artifacts/run-id` at startup.
2. **Raises the CSV field-size limit** to `2^31 - 1` bytes so massive `retrieved_context` cells never trigger a `_csv.Error: field larger than field limit`.
3. **Iterates every row**, and for each one:
   - Opens a `langwatch.trace(name=f"Batch_RAG_{run_id}")` context manager.
   - Inside it, opens a `langwatch.span(name="Retrieval", type="rag", input=query, output=truncated_context)` child span, where `retrieved_context` is **hard-truncated to 10,000 characters** before being sent, preventing HTTP 413 rejections.
   - Calls `retrieval_span.add_evaluation(name="exact_match_eval", passed=..., score=...)`:
     - `passed=True / score=1.0` when `generated_answer` is found as a verbatim substring of the (full, non-truncated) `retrieved_context`.
     - `passed=False / score=0.0` otherwise.
4. **Writes a summary JSON** to the path given by `--output`.
