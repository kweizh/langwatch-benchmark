### Key design decisions

| Concern | Approach |
|---|---|
| **Offline determinism** | `--offline` reads YAML directly from the path resolved in `prompts-lock.json` — zero network calls, zero SDK initialization |
| **Online with local-first** | Uses the real `langwatch` SDK with `FetchPolicy.MATERIALIZED_FIRST`; `source` is set to `"local_materialized"` when the SDK sources from the local file |
| **Variable substitution** | Custom `{{variable}}` regex scan; collects required variables from all messages before substitution; fails loudly (exit 2) if any are missing; verifies no `{{` remains post-compile |
| **Version resolution** | `--version` overrides; otherwise reads integer version from `prompts-lock.json` |
| **No mocking** | The real `langwatch` package (v0.26.0) is installed via `uv pip install langwatch` and imported directly |
| **Error handling** | Non-zero exits for missing variables, unknown handles, missing materialized files, and malformed `--vars` JSON |
