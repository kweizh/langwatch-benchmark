## Implementation Summary

### Environment & Configuration
- Reads `LANGWATCH_API_KEY`, `LANGWATCH_ENDPOINT`, `LANGWATCH_PROJECT_ID` from environment (never hardcoded).
- Reads the `run-id` from `/logs/artifacts/run-id` and builds the experiment name as `rag-eval-<run-id>`.

### Data Loading
- `load_dataset()` — reads `data/qa_dataset.csv` via `csv.DictReader` (6 QA rows).
- `load_knowledge_base()` — reads `data/knowledge_base.json` (8 document chunks).

### Deterministic RAG Pipeline
- **`retrieve(question, kb, top_k=2)`** — ranks KB documents by word-level Jaccard similarity and returns the top-2 content strings as a `list[str]` (no network calls, fully deterministic).
- **`generate(question, contexts)`** — extractively concatenates the retrieved chunks into a non-empty answer grounded in the contexts (no live LLM required).

### LangWatch Batch Evaluation
1. Calls `langwatch.setup(api_key=..., endpoint_url=...)` to configure the SDK.
2. Calls `langwatch.experiment.init(experiment_name, run_id=run_id)` which posts `BATCH_EVALUATION_V2` to `/api/experiment/init` — exactly one experiment creation with a name containing the run-id.
3. Iterates via `experiment.loop(dataset, total=len(dataset))` — the SDK's evaluation loop primitive that tracks every row.
4. Per row: calls `experiment.evaluate("legacy/ragas_context_utilization", index=index, data={"input": question, "output": output, "contexts": contexts}, settings={})` — invokes the built-in backend evaluator once per row with `contexts` as a proper `list[str]`.

### Output
- Writes `eval_summary.json` with `experiment_name`, `rows_evaluated`, and `evaluator` fields.
- Prints `Rows evaluated: 6` to stdout.
