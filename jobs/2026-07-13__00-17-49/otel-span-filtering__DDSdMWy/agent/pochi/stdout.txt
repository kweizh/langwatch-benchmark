## `configure_langwatch(tracer_provider)`

Calls `langwatch.setup(...)` with the **existing** `TracerProvider` passed in, along with two `SpanProcessingExcludeRule` objects:

| Rule | `field_name` | `match_operation` | `match_value` |
|------|-------------|-------------------|---------------|
| Health check | `span_name` | `exact_match` | `GET /health_check` |
| DB operations | `span_name` | `starts_with` | `db.` |

LangWatch attaches its own `FilterableBatchSpanProcessor` to the provider rather than replacing it — the pre-existing `SimpleSpanProcessor(ConsoleSpanExporter())` is untouched. Credentials are read from `LANGWATCH_API_KEY` / `LANGWATCH_ENDPOINT` environment variables.

## `run_pipeline(query)`

Uses `opentelemetry.trace.get_tracer(...)` (the global tracer) to create all spans through the shared global provider:

```
rag_pipeline  (root, parent_id=null)
├── GET /health_check     ← excluded from LangWatch (exact_match)
├── db.query.documents    ← excluded from LangWatch (starts_with "db.")
├── rag.retrieve          ← exported to LangWatch
└── llm.generate          ← exported to LangWatch
```

Returns a non-empty answer string derived from `query`.
