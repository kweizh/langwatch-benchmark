### What was built

**`SupportAgentAdapter`** — subclasses `scenario.AgentAdapter`, implements the required async `call` method, and returns a plain string that quotes the user's message and states the 30-day refund policy.

**`UserSimulatorAgent`** — configured with a system prompt that casts it as an impatient, frustrated customer disputing an undelivered order.

**Two `JudgeAgent` instances** with distinct, non-overlapping concerns:

| Judge | `criteria` |
|---|---|
| `politeness_judge` | Greeting tone, empathetic language, thanking the customer |
| `policy_judge` | Correct policy statement, offering to escalate, no over-promising |

**Script** uses the three required DSL helpers in order:
```
scenario.user(...)   →  scenario.agent()   →  scenario.succeed(...)
```

**Script-type detection** — each DSL helper returns a `lambda`. The script-type names (`"user"`, `"agent"`, `"succeed"`) are recovered by inspecting `__code__.co_freevars`, which contains the names of captured closure variables — a reliable, pure-Python technique that requires no live execution.

**No OpenAI keys needed** — `scenario.run` is never called. A placeholder model string (`"openai/gpt-4.1-mini"`) is supplied only to satisfy the agent constructors' validation; it is never used at runtime.
